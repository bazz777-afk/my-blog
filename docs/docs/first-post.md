# 我的第一篇博客：开源软件开发实践心得

## 一、实践目标
本次实践是开源软件开发课程的第一次作业，目标是基于 GitHub 工具链搭建个人博客网站，掌握 GitHub 仓库管理、Markdown 写作、GitHub Actions 自动化部署以及 GitHub Pages 网站发布的基础方法。

## 二、使用工具
本次实践使用 MkDocs 作为静态博客生成工具，配合 GitHub Actions 实现自动构建，最终通过 GitHub Pages 发布网站。全程通过 GitHub 网页端操作，无需本地安装开发环境。

## 三、实践收获
1.  掌握了 GitHub 公开仓库的创建与文件管理方法
2.  学会了使用 Markdown 基础语法编写格式规范的文档
3.  理解了 GitHub Actions 的自动化工作流原理，能够配置简单的部署脚本
4.  熟悉了 GitHub Pages 的发布流程，了解了静态网站托管的基本逻辑

## 四、后续规划
后续会持续在博客中更新课程学习笔记，记录实践过程中遇到的问题与解决方案，积累技术经验。
